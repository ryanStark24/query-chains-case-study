# Query Chains — design & engineering case study

A single-page case study for **Query Chains**, a Chrome extension that brings
SOQL querying, record-access inspection, debug-log diagnosis and platform-event
monitoring into the Salesforce tab you are already working in.

Live: https://ryanstark24.github.io/query-chains-case-study/

This repository contains the published page only. The extension's source is not
part of it.
